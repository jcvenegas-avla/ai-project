# Objetivos

Este framework busca:

* Desarrollo guiado por especificaciones.
* Alta trazabilidad entre negocio y código.
* Automatización mediante agentes de IA.
* Uniformidad en la creación de Jira.
* Mejor calidad del software.
* Documentación siempre sincronizada.
* Facilitar la colaboración entre personas y asistentes de IA.
