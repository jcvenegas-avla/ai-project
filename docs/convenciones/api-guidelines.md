# API Guidelines

El detalle de los lineamientos de API (Versionado, REST, GraphQL, Naming, Status Codes, Error Format, Authentication, Pagination, etc.) no vive en este documento — vive en cada proyecto, en la ruta `doc/IA/api-guidelines.md` de su repositorio o del Workspace correspondiente (ver [`docs/readme/proyectos.md`](../readme/proyectos.md)).

Todos los proyectos listados en esa tabla deberían tener ese archivo. Si un proyecto no lo tiene, `tech-lead` debe señalarlo antes de diseñar para ese proyecto, en vez de asumir un lineamiento no definido.
