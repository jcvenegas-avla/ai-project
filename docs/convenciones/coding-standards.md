# Coding Standards

El detalle de los estándares de código (convenciones de nombres, estructura de carpetas, Clean Code, SOLID, Testing, Logging, Error Handling, etc.) no vive en este documento — vive en cada proyecto, en la ruta `doc/IA/architecture.md` de su repositorio o en el Workspace correspondiente (ver [`docs/readme/proyectos.md`](../readme/proyectos.md)).

Todos los proyectos listados en esa tabla deben tener su propio documento de coding standards. Si un proyecto no lo tiene, `developer` debe señalarlo antes de implementar código para ese proyecto, en vez de asumir un estándar no definido.
